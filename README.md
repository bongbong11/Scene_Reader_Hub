# 씬판독기 Hub

최근 롤플레잉 대화를 읽고, 다음 답변에 필요한 진행과 인물의 반응 기준을 골라주는 SillyTavern 확장입니다. 이야기를 대신 완성하거나 모든 문제를 해결시키는 기능은 아닙니다. 현재 대화가 자연스럽게 움직이도록 돕습니다.

> **사용 전 알아두세요.** 실제 인물과 사건을 만들어 내는 것은 롤플레잉 답변을 작성하는 모델입니다. 씬판독기는 어떤 유형의 인물·사건·진행을 사용할지 분류하고 참고할 방향을 전달합니다. 사람이 직접 구상한 전개에 비해 만족스럽지 않을 수 있습니다. 판독 역시 Jev라는 모델이 수행하므로 오판이나 누락이 생길 수 있다는 점을 염두에 두고 사용하세요.

**Hub 0.1.18 · 기능 기준 씬판독기 0.26.2 · 공유 Jev 서버 플러그인 0.7.0**

인물 분석 기능은 Hub에 포함되어 있습니다. 기존 씬판독기의 Jev 서버 플러그인 0.7.0을 그대로 사용합니다. 이미 설치한 플러그인은 교체하지 않습니다. 처음 사용하는 분만 아래 플러그인을 설치하세요.

## 기존 씬판독기에서 교체

1. 기존 씬판독기에서 필요한 경우 기존 백업 기능으로 현재 상태를 보관합니다.
2. 기존 화면 확장만 제거하고 SillyTavern을 새로고침합니다.
3. 이 Hub 확장을 설치하고 다시 새로고침합니다.
4. 같은 사용자 계정과 같은 캐릭터/그룹 채팅을 열면 기존 설정·인물·세계관·이력·서버 키를 읽습니다. 자료를 다시 올릴 필요가 없습니다.
5. 이전 매크로는 빈 값으로 처리됩니다. **톱니바퀴 → 주입 위치**에서 프리셋 기준 항목과 앞·뒤를 선택하세요. 기본 주입을 쓰던 설정은 유지됩니다.

사용자 데이터 디렉터리와 서버 플러그인을 함께 삭제하지 마세요. 기존 확장과 Hub를 같은 채팅에서 동시에 켜지 않습니다. Hub가 최종 사용·배포 본체이며 기존 저장소는 수정 시험용으로 유지합니다.

## 창 크기 조절

창 **오른쪽 아래 손잡이를 잡아당겨** 가로·세로 크기를 조절합니다. 모바일에서도 손가락으로 끌 수 있습니다. 크기는 이 브라우저에서 기억하며, 손잡이를 두 번 누르면 기본 크기로 돌아갑니다. 화면 높이가 줄어들면 자동으로 맞추고 각 탭의 마지막 항목까지 스크롤할 수 있습니다.

## 현재 상태 확인

로그 복사 옆 원형 버튼을 누르면 임베딩·검색·판독·저장·주입 결과가 나옵니다. 빨강은 확인할 문제, 초록은 필요한 단계 확인 완료, 회색은 대기·진행·확인 전입니다. 오류가 생기면 채팅창 끼끼의 표정도 바뀌고, 정상 복구를 확인하면 원래 얼굴로 돌아옵니다. 끼끼는 기존처럼 확장 창을 여는 버튼이며, 상세 상태는 원형 버튼으로 확인합니다.

## 실행 흐름 확인

**실행 흐름**은 설정에서 개발자 모드를 해제했을 때만 표시됩니다. 일반 화면에서도 판독 결과와 오류 안내를 확인하고, 상단 **전체 진단 로그 복사**를 사용할 수 있습니다. 복사한 기록에는 전체 대화·API 키·주입 원문을 넣지 않습니다.

‘주입 준비됨’은 실제 모델 전송과 구분합니다. 전송 요청에서 주입문 포함을 확인하면 전송문 확인 기록이 남습니다. 선택한 프리셋 항목을 찾지 못했거나 요청 내용을 확인할 수 없으면 확인되지 않은 상태로 표시합니다.



최근 변경 사항은 [업데이트 내역](CHANGELOG.md)에서 확인할 수 있습니다.

## 빠른 답장용 슬래시 명령어

빠른 답장 내용에 아래 명령어를 넣으면 됩니다. 명령어 결과는 다음 명령에 전달되며 채팅 메시지를 자동 전송하지 않습니다.

| 명령어 | 동작 |
| --- | --- |
| `/srh-open` | 씬판독기 창 열기 |
| `/srh-judge` | 지금 판독 버튼 실행. 판독·저장·주입 준비가 끝날 때까지 대기 |
| `/srh-auto on` / `/srh-auto off` | 생성 직전 자동 판독 켜기·끄기 |
| `/srh-enabled on` / `/srh-enabled off` | 확장 전체 켜기·끄기. off는 판독과 주입 중단 |
| `/srh-clear` | 진행 중인 Hub 판독 취소 및 현재 주입 해제. 기존 데이터 유지 |
| `/srh-status` | 실행 상태를 JSON으로 반환 |

자동 판독·전체 사용 명령은 `toggle`로 전환하거나 인수를 생략해 현재 값만 확인할 수 있습니다. 현재 상태를 알림으로 보려면 `/srh-status | /echo {{pipe}}`를 사용하세요. 판독 버튼용 빠른 답장은 `/srh-judge`만 넣으면 됩니다.

`/srh-judge`는 입력창의 RP 초안도 읽습니다. 입력창이 `/`로 시작하면 명령문을 RP로 읽지 않고 저장된 대화를 판독합니다. 같은 응답을 다시 판독해도 등장 확률을 추가 추첨하지 않습니다. `/srh-clear`는 일회성 해제이므로 다음 판독·생성에서 다시 주입될 수 있습니다. 지속 중단은 `/srh-enabled off`를 사용하세요. `/srh-auto off`는 자동 판독 설정만 끄며 전체 주입 중단과는 다릅니다.


## 사건·인물 등장 기회

새 RP 입력이나 새 답변 이후 다음 응답을 만들 때 새 생성 기회를 확인합니다. 같은 응답의 재판독·리롤·새로고침은 동일 추첨을 사용합니다. 사건과 인물은 각각 한 번 추첨하고, 당첨 뒤에는 가능한 실행 방법을 고릅니다. 현재 대화에 대한 직접 응답이 선택됐다는 이유로 추가 생성을 제외하지 않습니다.

저장된 NPC·빌런이 있어도 새 인물 후보를 검토합니다. 새 인물이 실제 답변에서 확인되면 이전 인물을 기록에 보관하고, 이후 장면에 맞으면 다시 선택할 수 있습니다. 추첨 통과는 실제 등장 보장이 아니며 장면 적합성·응답 내 우선순위도 적용됩니다. 결과 화면과 전체 진단 로그에 제외된 단계를 표시합니다.


## 처음 사용하는 분께

1. 아래 순서로 확장과 서버 플러그인을 설치합니다.
2. 씬판독기의 톱니바퀴를 열어 **Jev API 키 → 키 저장 → 연결 확인**을 누릅니다.
3. **자동 전개**에서 기본 전개 성향을 **균형**으로 두고 먼저 사용해 봅니다.
4. 인물 판정 탭에서 시트와 필요한 로어북을 가져와 분석 명령문을 복사하고, 외부 AI에서 받은 JSON 파일을 **검증 후 저장·적용**합니다.
5. 고급 전개와 갈등용 진행은 원하는 기능만 켭니다. 처음부터 모두 켤 필요는 없습니다.

설정은 처음에는 기본값으로 두세요. 진행이 답답하거나 과할 때만 톱니바퀴 안의 **진행 적극성**을 조금씩 조절하면 됩니다.

## 설치

### 1. 화면 확장

SillyTavern의 **확장 → 확장 설치**에 다음 주소를 입력합니다.

```text
https://github.com/bongbong11/Scene_Reader_Hub.git
```

설치 후 화면을 새로고침합니다. **실리태번 확장 탭 → 씬판독기**를 펼치면 **씬판독기 사용**, **채팅창 아이콘 표시**, **씬판독기 열기**가 있습니다. 이 항목은 처음에는 접혀 있습니다.

채팅 입력창 옆 아이콘이나 마법봉 메뉴에서도 열 수 있습니다. 아이콘 표시를 꺼도 판독 기능은 계속 사용할 수 있고, 실리태번 확장 탭의 **씬판독기 열기**로 화면을 열면 됩니다.

판독·검색·저장 등의 알림은 캐릭터 그림과 함께 나타납니다. 진행 중 알림은 실제 작업 단계에 맞춰 바뀌며, 완료·주의·오류 알림은 읽을 시간을 두고 사라집니다. 알림을 누르면 바로 닫을 수 있고 진행 중인 작업은 계속됩니다. 모바일에서는 여백과 그림 크기를 줄여 표시합니다.

Hub는 위 GitHub 주소로 설치하고 확장 목록의 업데이트 기능으로 갱신합니다. 이미 공유 Jev 서버 플러그인을 사용하고 있다면 그대로 사용할 수 있습니다.

### 2. Jev 서버 플러그인

[서버 플러그인 ZIP 다운로드](https://raw.githubusercontent.com/bongbong11/-_-/main/downloads/scene-reader-jev-plugin-v0.7.0.zip)를 눌러 파일을 받고 압축을 풉니다. 안에 있는 **scene-reader-jev 폴더 전체**를 SillyTavern의 **plugins** 폴더에 넣습니다. 화면 확장과 설치 위치가 다릅니다.

최종 위치는 다음과 같습니다.

```text
SillyTavern/plugins/scene-reader-jev/package.json
SillyTavern/plugins/scene-reader-jev/index.cjs
SillyTavern/plugins/scene-reader-jev/storage.cjs
SillyTavern/plugins/scene-reader-jev/retrieval-cache.cjs
```

SillyTavern의 `config.yaml`을 메모장으로 열고 다음 설정을 켭니다.

```yaml
enableServerPlugins: true
```

저장한 뒤 **SillyTavern을 완전히 종료하고 다시 시작**하세요. 브라우저 새로고침만으로는 서버 플러그인이 켜지지 않습니다. `enableCorsProxy`는 켤 필요가 없습니다.

서버 플러그인은 **0.7.0**이 필요합니다. 이미 0.7.0을 사용한다면 다시 교체할 필요가 없습니다. 이전 버전이라면 위 ZIP의 폴더 전체를 기존 플러그인 폴더에 덮어쓰고 SillyTavern을 다시 시작하세요. 기존 설정·인물·채팅별 자료는 이어서 사용하며, 사용자 데이터 폴더나 다른 플러그인은 삭제하지 마세요.

GitHub의 **Code → Download ZIP**으로 저장소 전체를 받았다면, 압축 안의 `server-plugin` 폴더를 `scene-reader-jev`로 이름을 바꾸어 위 `plugins` 위치에 넣으면 됩니다. 폴더 안에 `index.cjs`가 바로 있어야 합니다.

휴대전화에서도 서버가 실행되는 SillyTavern 폴더의 `plugins`에 넣어야 합니다. 브라우저의 다운로드 폴더에 파일을 받기만 해서는 설치되지 않습니다. 다른 사람이 운영하는 서버라면 서버 관리자에게 설치를 요청하세요.

### 3. 연결하기

씬판독기 오른쪽 위 **톱니바퀴 → 모델·키 설정 → Jev 판독**에서 **키 발급처를 선택하고**, 발급받은 키 하나를 입력한 뒤 **키 저장**을 누릅니다. TypeSafe 공식·OpenRouter·Vercel AI Gateway를 지원하며, 주소와 모델은 입력하지 않습니다. 저장할 때 짧은 판독 요청으로 연결을 확인합니다.

**키 발급처는 직접 선택해야 합니다.** 공홈 · TypeSafe, OpenRouter, Vercel AI Gateway 중 실제로 키를 발급받은 서비스를 선택하세요. 기존에 저장한 키가 있으면 그 발급처가 표시됩니다. 새 키 입력이나 발급처 변경 후에는 **키 저장**을 누르세요. **저장된 키 연결 확인**은 이미 저장한 키를 다시 검사하는 버튼입니다. 키를 여러 서비스에 보내 추측하지 않습니다.

TypeSafe 키는 기존 서버 저장 방식을 유지합니다. OpenRouter·Vercel 키는 **현재 브라우저에만 저장**하므로 PC·모바일에서 각각 입력해야 하며, 브라우저 저장 자료를 지우면 다시 입력해야 합니다. 다운로드 백업에는 키를 포함하지 않습니다. 이 두 서비스를 사용할 때는 판독에 필요한 대화와 기록이 선택한 서비스로 직접 전달됩니다. 자료 저장에는 기존 서버 플러그인을 계속 사용하므로 플러그인은 교체하지 않습니다.

이미 만든 인물·고급 세계관 JSON을 가져오는 데에는 별도의 연결 프로필이 필요하지 않습니다. 일반 세계관의 짧은 설명을 자동으로 만들거나, 선택 기능인 연속성 추론을 사용할 때에는 **설정의 확장 연결모델**을 사용합니다. SillyTavern의 **API 연결 메뉴에 연결 프로필을 저장**한 뒤 씬판독기 설정의 **SillyTavern 연결 프로필**에서 선택하세요. **프로필 새로고침**을 누르면 새로 저장한 연결이 목록에 나타납니다.

설정의 **임베딩 모델·키 선택**은 항상 펼쳐 표시됩니다. 기본값은 키가 필요 없는 **SillyTavern 로컬**이며, **Gemini · AI Studio**, **Gemini · Vertex AI**, **NanoGPT Qwen**도 선택할 수 있습니다. AI Studio 키는 AI Studio를, Vertex Express 키는 Vertex AI를 선택한 뒤 **새 키 입력 → 키 저장 → 연결 확인**으로 설정하세요. 선택한 서비스에 저장된 인증 정보가 있으면 다시 입력하지 않아도 됩니다. Gemini 모델은 자동으로 설정되고, Vertex 리전은 global로 고정됩니다. Vertex 서비스 계정 JSON은 SillyTavern 연결 설정에서 등록합니다. 로컬도 임베딩 모델을 사용하며, 임베딩을 완전히 끄는 설정은 없습니다.

**키 저장됨**은 저장 여부이며, 실제 사용 가능 여부는 **연결 확인**으로 확인합니다. 키는 SillyTavern의 키 저장소에 보관되며 씬판독기의 설정·다운로드 백업에는 넣지 않습니다. 검색 서비스를 바꿔도 인물·세계관 파일을 다시 만들 필요는 없습니다. 검색 데이터가 준비되지 않거나 실패하면 창 위쪽의 **임베딩 재시도**을 눌러 현재 채팅에 등록된 인물과 선택한 세계관의 검색 색인을 확인합니다. 정상 기록은 재사용하고 누락·실패한 기록만 생성합니다. 전체 재계산이 필요할 때만 설정의 **전체 임베딩 다시 만들기**를 사용하세요. 완료 후 **지금 판독**을 눌러 주세요. 임베딩 재시도은 판독을 실행하지 않으며, 원본 인물·세계관 기록을 삭제하지 않습니다.

로컬 검색은 SillyTavern 서버의 내장 임베딩을 사용하며 API 키가 필요 없습니다. 검색 연결은 SillyTavern **1.18.0**의 기능을 기준으로 확인했습니다. 외부 서비스를 고르면 후보 검색을 위해 저장된 판독 기록과 최근 장면 일부가 해당 서비스로 전달됩니다. 연결 실패나 시간 초과가 발생하면 글자 기준으로 후보를 찾고 Jev 판독을 이어갑니다. 화면의 검색 상태에서 대체 검색 여부를 확인할 수 있습니다.

## 업데이트할 때

먼저 설정의 **데이터 백업 → 지금 백업**으로 저장본을 남겨두는 것을 권합니다. 확장 관리 화면에서 업데이트한 뒤 새로고침하세요. ZIP으로 업데이트할 때는 `src` 폴더를 포함해 압축 내용 전체를 기존 확장 폴더에 덮어씁니다.

**0.16.3 이하의 인물 규칙은 새 방식으로 다시 추출해야 합니다.** 인물 판정 탭에서 새 판독 JSON 파일을 가져오세요. 기존 자료는 보관되지만, 재추출 전에는 새 인물 기록으로 적용되지 않습니다.

나중에 인물 분석 기준이 업데이트되면 일부 시트에 **재판독 필요**가 표시될 수 있습니다. 캐릭터·페르소나는 현재 시트와 로어북을 다시 가져와 새 JSON을 만들고, NPC는 작성해 둔 시트나 로어북으로 새 JSON을 만드세요.

이번 업데이트에서도 기존 날짜별 인물 파일을 그대로 사용할 수 있습니다. 새 분석 기준으로 기록을 보완하고 싶을 때만 파일을 다시 만드세요.

## 자동 전개

평소 대화·감정·행동의 흐름을 정하는 탭입니다. 작은 행동이나 대화의 변화도 진행으로 봅니다. 고급 전개를 끈 상태에서도 작동합니다.

### 세계 반응과 관계 방향

**세계 반응**은 주변 상황이 어떻게 반응할지, **관계 방향**은 인물이 사용자에게 보이는 기본적인 태도를 정합니다. 호의적이라고 바로 사랑에 빠지거나, 적대적이라고 모든 사건이 적대적으로 바뀌는 것은 아닙니다. 인물의 실제 시트와 대화 근거를 함께 따릅니다.

### 기본 전개 성향

| 선택 | 중심이 되는 진행 |
|---|---|
| 정적 | 두 사람의 관계·감정·생각, 의미 있는 대화의 변화 |
| 균형 | 감정·대화와 행동·주변 반응을 상황에 맞게 섞음 |
| 동적 | 활발한 행동·상호작용·주변 반응, 상황을 움직이는 시도 |

정적은 아무것도 하지 않는다는 뜻이 아닙니다. 조용한 대화에서 새로운 속내가 드러나도 진행입니다. 동적이라고 무조건 큰 사건을 만들거나 관계를 빨리 바꾸지는 않습니다.

말과 분위기만 바뀌고 같은 내용을 반복하면, 대화의 접근을 바꾸거나 작은 행동을 시도하도록 돕습니다. 모든 문제를 한 번에 해결하거나 상대의 선택까지 대신 결정하지는 않습니다.

**글의 길이·서술 속도·장르·문체는 메인 프롬프트와 프리셋을 따릅니다.** 별도의 RP 호흡 설정은 없습니다.

### 관계 진전 속도

가까워지거나 멀어지는 변화의 폭입니다. 느리게는 작은 변화와 쌓인 계기를, 빠르게는 충분한 계기가 있을 때 더 큰 변화를 허용합니다. 호감뿐 아니라 거리 두기·거절·갈등에도 적용됩니다.

느리게 해도 같은 말을 반복해야 하는 것은 아닙니다. 동적으로 설정해도 관계만 천천히 변하게 할 수 있습니다.

### 사건 해결 속도

진행 중인 문제를 이번 답변에서 얼마나 해결에 접근시킬지 정합니다. 느리게는 단계별 진전을, 빠르게는 조건이 갖춰졌을 때의 해결을 우선합니다. 이미 해결된 일을 일부러 되돌리거나, 해결 근거가 없는데 끝내지는 않습니다.

### 육체적 진행 단계

감정적 관계 진전과 별도로 **극도의 슬로우번·느리게·중간·빠르게·무절제** 중에서 고릅니다. 기본값은 **중간**입니다. 캐릭터와 프리셋의 설정을 참고하며, 느린 단계에서는 행동하지 않고 내면에 유지할 수도 있습니다. 구체적인 표현은 롤플레잉 모델과 프리셋을 따릅니다.

| 선택 | 사용하는 기준 |
|---|---|
| 극도의 슬로우번 | 직접적인 접근은 매우 천천히 이어가며, 내면의 욕망·절제나 작은 행동은 남깁니다. |
| 느리게 | 작은 접근을 천천히 이어가거나, 속으로 원하면서도 행동하지 않을 수 있습니다. 같은 망설임과 확인 질문만 반복하지 않습니다. |
| 중간 | 생각이나 분위기에만 머물지 않고 인물에 맞는 말·접근·행동으로 이어갑니다. |
| 빠르게 | 행동할 기회가 있을 때 접근과 후속 행동을 적극적으로 이어갑니다. |
| 무절제 | 충동적이며 수치심이나 장소·체면을 크게 따지지 않는 행동을 표현합니다. |

**관계 진전 속도**와 따로 고르므로, 관계는 느리게 변해도 육체적 진행은 다른 단계를 사용할 수 있습니다. 상태창의 감정 퍼센트를 직접 바꾸는 설정은 아닙니다. 인물 판정을 켜고 사용할 인물을 등록해 두세요. 페르소나는 유저 사칭 허용을 켠 경우에만 포함됩니다. NPC는 인물별 **성적 충동·자제력 추가 판독**을 켜 주세요.

### 새 사건·인물 생성과 돌발 추가

**자동 전개** 탭의 **새 사건·인물 생성**을 끄면 확장이 새로 제안하는 사건과 인물 생성만 멈춥니다. 현재 대화에 대한 반응, 관계 표현, 이미 이어지고 있는 사건과 인물의 행동은 계속 사용할 수 있습니다. 처음에는 켜져 있습니다.

**돌발 추가**는 끄기·사건·인물·둘 다 중 고릅니다. 처음에는 꺼져 있으며, 켜면 기존 사건의 복선이 없어도 장면에 맞는 작은 변화나 접근 가능한 인물의 개입을 제안합니다. 사건 확률은 돌발 사건 또는 고급 전개가 켜져 있을 때 적용됩니다.

현재 상호작용에 대한 답변을 기본으로 두고, 선택된 사건과 인물을 함께 반영합니다. 한 응답에 새 사건 하나와 새 인물 하나까지 제안하며, 진행 중인 중심 사건을 새 사건으로 덮어쓰지 않습니다. 돌발은 세계관·출입 경로·유저의 명시적 제약을 무시하는 설정이 아닙니다.

### 공통 인물 등장 확률

새 일반 NPC와 새 빌런의 등장 추첨에 사용합니다. **5·10·20·35·50·75·100%** 중 선택합니다.

추첨에 당첨되면 제시된 후보 중 가능한 등장 방법을 고릅니다. 방문·마주침·현재 활동 참여·주변 인물의 개입·연락 등 상황에 맞는 방법을 쓰며, 정적이거나 감정에 집중한 장면이라는 이유만으로 제외하지 않습니다. 빌런 사용을 켜면 같은 인물 추첨 안에서 일반 인물 또는 빌런을 고릅니다.

100%는 등장 추첨을 통과한다는 뜻입니다. 장소나 설정상 불가능한 등장까지 강제하지는 않습니다. 같은 입력을 다시 판독할 때 계속 재추첨하지 않으며, 기존 인물이 행동하는 데에는 등장 추첨이 필요하지 않습니다.

### 지금 판독과 결과

**지금 판독**을 누르면 현재 입력과 최근 대화를 확인합니다. **이번 턴 최종 적용**에서 실제로 선택된 진행을 먼저 확인하세요. 그 아래에서 현재 사건·인물과 자세한 판정 내용을 볼 수 있습니다.

현재 상호작용에 답하면서 선택된 추가 사건·인물을 반영합니다. 두 가지가 함께 선택되면 자연스럽게 연결할 수 있는 경우에만 묶고, 억지로 별개 줄거리를 늘리지 않습니다. 관계 표현과 인물 기록은 함께 적용됩니다. 결과 화면에서 준비됨·실제 요청 포함·답변 이행 확인을 구분해 볼 수 있습니다.

**검증 대기**는 계획을 골랐지만 실제 답변에서 실행됐는지 아직 확인하지 않았다는 뜻입니다. 선택했다고 바로 발생한 일로 저장하지 않습니다. **사건 끝내기**는 확장이 추적하는 사건을 정리하는 버튼이며, 실제 채팅을 수정하지 않습니다.

## 고급 전개

기본 흐름 위에 별도의 이벤트를 더하는 기능입니다. **고급 전개 사용**을 켜고 원하는 요소를 선택하세요. 탐험·위협·세력·비밀 등 화면에 있는 요소 중 필요한 것만 켜면 됩니다.

고급 전개를 켜도 기본 전개 성향과 관계·해결 속도는 계속 적용됩니다. 이벤트가 불발돼도 현재 대화와 행동은 이어갑니다.

**자동 전개 → 사건 확률**에서 18·35·58·75% 중 선택합니다. 새로운 이벤트에만 적용하며 이미 진행 중인 이벤트는 다시 추첨하지 않습니다. 사건의 크기나 글의 속도를 정하는 설정은 아닙니다.

### 세계관 선택과 관리

세계관은 가능한 상황의 큰 틀을 제공합니다. 실제 장르와 문체는 프리셋을 따릅니다. 특정 요소를 켰다고 세계 설정에 없는 능력이나 존재를 자동으로 추가하지 않습니다.

**자동 전개**에서 세계관을 선택합니다. 세계관을 선택해도 고급 이벤트를 반드시 켤 필요는 없습니다. **고급 전개 → 세계관 관리**를 펼치고 **+**를 누르면 원하는 세계관을 추가할 수 있습니다.

1. 이름과 세계관 원문을 넣습니다.
2. **짧은 세계관 설명**에는 판독에 필요한 큰 규칙을 적습니다. 비우고 저장하면 **설정의 확장 연결모델**이 원문을 읽고 짧은 설명을 만듭니다. 직접 설명을 적으면 모델 호출 없이 저장합니다.
3. **저장**을 누릅니다. 생성이나 저장에 실패하면 입력을 유지하므로 내용을 확인하고 다시 시도할 수 있습니다.
4. 자동 전개 탭에서 저장한 세계관을 선택합니다. 수정·삭제는 세계관 관리 목록에서 다시 열어 진행합니다.

**원작·프랜차이즈 세계**를 켜면 장소·시대·역할에 맞는 원작 인물도 등장 후보로 고려합니다. 무조건 유명 인물을 등장시키는 옵션은 아닙니다.

같은 **세계관 관리** 안의 **고급 세계관 추가**는 긴 세계관 원문을 나누어 쓰고 싶을 때 선택하는 방식입니다. 인물 판독 파일과 비슷하게, 먼저 원문을 JSON 파일로 정리해 저장하고 매 턴 필요한 항목만 고릅니다. 저장 결과에는 **세계관 이름**, Jev가 판독할 때 참고하는 **짧은 설명**, 선택 여부와 관계없이 들어가는 **고정 규칙**, 해당 장소·시기·상태 등 조건이 맞는 장면에서만 고를 **장면별 규칙**이 담깁니다. 한 규칙의 조건·예외는 함께 유지하며, 세계관의 사실을 등장인물 모두의 지식으로 취급하지 않습니다.

1. **분석 명령문 복사**를 눌러 AI 서비스에 붙여 넣습니다. 선택하거나 작성한 세계관 원문이 있으면 함께 복사됩니다. 원문이 없으면 기본 명령문만 복사되므로, 나누려는 세계관 원문을 외부 AI에 함께 넣어 JSON 결과를 받으세요. 복사 버튼 주변 안내와 복사 완료 알림에서 원문 포함 여부를 확인할 수 있습니다.
2. **JSON 파일 가져오기**로 결과 파일을 올리거나 **고급 세계관 JSON** 칸에 내용을 붙여 넣습니다.
3. 결과를 확인한 뒤 **검증 후 저장**을 누릅니다. 업로드만으로는 저장되지 않습니다.
4. 자동 전개 탭에서 저장한 세계관을 선택합니다. 수정·삭제는 세계관 관리 목록에서 해당 이름을 눌러 진행합니다.

일반 **+**로 추가한 세계관은 원문 전체를 지정한 위치에 전달합니다. **고급 세계관**은 인물 판독과 비슷하게 저장된 규칙 중 현재 장면에 필요한 내용을 골라 **고정 규칙과 함께** 전달합니다. 필요한 장면별 규칙이 없거나 판독에 실패해도 고정 규칙은 남고, 실패한 경우 화면에 안내합니다. 장면의 종류와 관계없이 필요한 세계관 설정을 참고합니다. 일반 방식으로 저장한 원문이 자동으로 나뉘거나 덮어써지지는 않습니다.

일반 주입문에는 현재 선택한 세계관 이름만 짧게 표시합니다. 세계관 규칙은 별도로 지정한 위치에 들어갑니다. **톱니바퀴 → 주입 위치 → 세계관 규칙·시즌 참고 주입**에서 기본 주입 또는 프리셋 항목 앞·뒤를 선택하세요.

### 현대 배경 추가 참고

자동 전개의 세계관 선택 아래 **현대 배경 추가 참고**를 펼치면 다음 항목을 따로 선택할 수 있습니다. 처음에는 모두 꺼져 있습니다.

| 선택 | 참고하는 배경 |
|---|---|
| 시즌 행사 | 할로윈·크리스마스·부활절 무렵의 분위기와 일상 변화 |
| 미식축구 대학리그 | 미국 대학 미식축구 시즌의 경기·캠퍼스 분위기 |
| 미식축구 프로리그 | 미국 프로 미식축구 시즌의 주변 분위기 |
| 미국 대학 | 가을·봄 학기, 시험과 방학의 일반적인 흐름 |
| 영국 대학 | 가을·봄·여름 학기와 평가·방학의 일반적인 흐름 |

최근 판독 범위의 **RP 본문에 적힌 날짜**를 참고합니다. 실제 오늘 날짜나 메시지를 보낸 시각은 사용하지 않습니다. `2026-10-30`, `2026년 10월 30일`, `October 30, 2026` 같은 표기를 읽으며, 날짜가 없으면 덧붙이지 않습니다. 부활절은 연도와 날짜가 있어야 계산할 수 있습니다.

학교별 정확한 학사 일정이나 실제 경기표를 조회하는 기능은 아닙니다. 평균적인 시기를 참고하며, 선택한 세계관에 같은 일정 규칙이 있으면 중복해서 넣지 않습니다. 행사를 이미 일어난 사건으로 만들거나 반드시 참여시키지는 않습니다. 미국·영국 대학 배경도 각각 선택할 수 있고, 해리포터 세계에는 호그와트의 주요 학기·휴일 흐름이 포함되어 있습니다.

이 참고문도 **세계관 주입 위치**로 전달됩니다. 세계관을 ‘현재 설정 따름’으로 두어도 사용할 수 있습니다. 프리셋 항목 앞·뒤를 사용한다면 기준 항목이 활성화되어 있어야 합니다.

## 갈등용 진행

싸움 유지·빌런·NPC의 자율적인 반응·세계 적대성 등 원하는 항목만 사용하세요. 실제 갈등이 없는 장면을 무조건 싸움으로 바꾸는 설정은 아닙니다.

**부정 편향을 최우선으로 사용**은 이 탭에서 켠 부정적 방향을 주변 상황과 사건 진행에서 우선하도록 합니다. 등록한 인물의 성격·관계·지식을 지우는 기능은 아닙니다. 부정적 항목을 많이 켜면 진행 적극성과 무관하게 이야기 분위기가 거칠어질 수 있으니 목적에 맞게 선택하세요.

## 인물 판정

인물 시트와 필요한 로어북을 판독 JSON으로 정리해 저장합니다. 실제 RP에서는 이번 장면에 필요한 기록만 골라 씁니다. 인물 판정 탭 안에서 **캐릭터·페르소나·NPC**를 추가하고, 각 이름 아래에 날짜별 저장본을 확인합니다.

원본 시트는 SillyTavern의 캐릭터 카드나 로어북에서 관리하세요. 이 탭의 원문은 판독 파일을 만들고 확인하기 위한 자료입니다. 실제 답변에는 저장된 판독 기록 중 필요한 내용만 전달하므로, 여기에 원문을 저장하는 것만으로 캐릭터 카드나 로어북을 대신하지는 않습니다.

### 캐릭터와 페르소나

1. **＋ 캐릭터** 또는 **＋ 페르소나**를 누릅니다.
2. **시트 가져오기**를 누릅니다. 캐릭터는 카드의 **캐릭터 설명과 성격 요약**을 함께 읽습니다.
3. 가져오기가 끝나면 버튼이 **시트 확인하기**로 바뀝니다. 누르면 시트 원문을 팝업에서 읽을 수 있고, 작은 **다시 가져오기** 버튼으로 갱신할 수 있습니다.
4. **연결 로어북 엔트리 고르기**를 펼친 뒤 책 이름을 눌러 필요한 엔트리만 체크합니다. 새 인물은 아무 엔트리도 선택되지 않은 상태로 시작하고, 기존 저장본을 수정할 때는 선택했던 엔트리가 복원됩니다.
5. **분석 명령문 복사**를 눌러 외부 AI에 붙여 넣습니다. 시트나 로어북을 가져오지 않아도 기본 명령문을 복사할 수 있습니다. 가져온 시트와 체크한 엔트리가 있으면 함께 복사되며, 버튼 주변 안내와 복사 완료 알림에서 포함 여부를 확인할 수 있습니다. 기본 명령문만 복사했다면 원문을 외부 AI에 따로 함께 제공하세요.
6. 완성된 **JSON 파일 업로드** 후 **검증 후 저장·적용**을 누릅니다.

### 카드 하나에 여러 인물이 있는 경우

**＋ 캐릭터 → 다인 캐릭터**에서 시트를 가져오고, 분리할 인물 이름을 2~6명 입력합니다. 시트와 이름을 비운 상태에서도 기본 명령문을 복사할 수 있으며, 이때는 외부 AI에 원문과 분리할 주요 인물들을 함께 알려 주세요. 분석 명령문은 같은 원문에서 각 인물의 성격·관계·지식·반응 기준을 따로 정리하도록 안내합니다. 외부 AI가 만든 **JSON 파일 하나**를 올린 뒤 인물별 미리보기를 확인하고 묶음 이름을 정해 저장하세요. 누락되거나 잘못된 인물이 있으면 파일을 고친 뒤 다시 올립니다.

단일 캐릭터·다인 캐릭터·페르소나·NPC·세계관의 분석 명령문에는 각각 필요한 JSON 구조, 필수 항목과 허용값, 흔한 오류, 제출 전 확인 방법이 포함됩니다. 시트 내용을 항목별로 정리한 일반 JSON은 판독 파일과 형식이 다를 수 있으므로, 확장에서 복사한 명령문 전체를 사용하세요.

저장 목록은 **묶음 이름 · 3명 → A / B / C → 각 인물의 저장 날짜**처럼 표시합니다. 같은 묶음이어도 장면 참여 여부와 필요한 기록은 인물별로 판독합니다. 카드 이름이 같다는 이유만으로 모든 인물의 기록을 함께 주입하지 않습니다. 이후 한 사람만 수정하거나 이전 저장본을 적용할 수도 있습니다. 한 명짜리 기존 파일은 **단일 캐릭터**에서 그대로 사용합니다.

### NPC

1. **＋ NPC → 시트 서식 복사**를 누르고 NPC 한 명의 시트를 작성합니다.
2. 역할을 **양면·선역·악역** 중에서 고릅니다. 캐릭터와 페르소나에 연결된 로어북에서 NPC 자료를 가져오려면 책을 펼쳐 **해당 NPC의 엔트리만** 체크합니다. **로어북의 NPC 시트는 한 명을 기준으로 작성되어 있어야 합니다.** 엔트리를 고르지 않아도 분석 명령문을 복사할 수 있습니다.
3. **분석 명령문 복사**를 누릅니다. 엔트리를 고르지 않았다면 작성한 NPC 시트를 명령문과 함께 외부 AI에 넣으세요. 엔트리를 골랐다면 선택한 원문이 복사문에 이미 들어 있습니다. JSON 파일로 결과를 받습니다.
4. **JSON 파일 업로드 → 검증 후 저장·적용**을 누릅니다.

업로드 시 JSON 형식과 기록 규칙을 검사합니다. 안전하게 정리할 수 있는 형식 오류는 자동으로 고치며, 내용이 빠졌거나 확인할 수 없는 결과는 저장하지 않습니다. 캐릭터·페르소나는 가져온 시트·선택한 로어북의 출처 번호도 확인합니다. NPC 시트를 AI에 따로 전달했다면 원문 내용까지 자동 대조하지는 않습니다.

### 저장된 기록과 날짜별 파일

**저장된 인물 기록**에서 캐릭터·페르소나·NPC 탭을 고릅니다. 이름을 누르면 적용 중인 파일을 먼저 열고, 적용 중인 파일이 없으면 최신 파일을 엽니다. 각 날짜의 **보기**는 그 날짜의 시트·선택한 로어북 원문과 판독 기록을 팝업에서 보여줍니다. 원문이 없는 파일은 원문 탭을 숨깁니다. 날짜별 **수정·삭제**는 해당 파일에 연결되며, 수정은 새 JSON을 업로드해 **새 날짜 버전**으로 저장합니다. 이전 파일로 돌아가려면 그 날짜의 **적용**을 누르세요. 적용 중인 파일을 삭제하면 해당 기록의 적용이 해제됩니다.

기록에는 성향·가치관·관계·지식·반응·표현·경계·능력 등이 담깁니다. **이번 턴 인물 판정**에서 이번 장면에 어떤 기록이 선택되어 주입문에 포함됐는지 확인할 수 있습니다. 실제 전송 요청에 포함됐는지는 상단 실행 흐름의 전송문 확인 기록에서 따로 확인합니다. 선택한 기록이 0개여도 저장한 인물이 사라지거나 새 NPC로 바뀌지는 않습니다. 검색 오류나 주입량 제한으로 빠진 내용은 결과에서 확인하세요.

기존 검색 후보를 유지하면서 빠진 **경계·모름·오해** 기록을 추가로 검토합니다. 해당 인물의 참여와 대상·시간·상황 조건이 맞아야 사용하며, 이미 선택된 기록을 밀어내지 않고 남은 선택 칸과 길이 안에서만 보강합니다. 최신 RP에서 직접 알게 된 사실을 과거의 모름 상태로 고정하지 않습니다. 결과의 **경계·지식 제한 보강**에서 추가 판독 수와 적용되지 않은 이유를 확인할 수 있습니다.

**캐릭터·페르소나 판독 주입량 · 현재 채팅**은 인물 탭에서 조절합니다. 처음에는 **넉넉하게**입니다.

| 선택 | 캐릭터·페르소나 각 기록 상한 | 전체 인물 주입 한도 |
|---|---:|---:|
| 기본 | 4개 | 3,000자 |
| 넉넉하게 | 6개 | 5,000자 |
| 상세하게 | 8개 | 8,000자 |

**NPC 판독 주입 개수 · 현재 채팅**은 별도로 고릅니다. **간결하게 2개 / 기본 3개 / 넉넉하게 4개**이며, 처음에는 **기본 3개**입니다. NPC가 여러 명이면 각 NPC에 이 개수가 적용됩니다. 항상 정해진 개수를 채우는 것은 아닙니다.

| NPC 선택 | NPC 한 명당 기록 상한 | 선택할 때 |
|---|---:|---|
| 간결하게 | 2개 | NPC가 여러 명이거나 전달 내용을 줄이고 싶을 때 |
| 기본 | 3개 | 평소 사용할 기본값 |
| 넉넉하게 | 4개 | NPC의 성격·관계·지식 기준을 더 참고하고 싶을 때 |

전체 글자 한도는 캐릭터·페르소나·NPC가 함께 사용합니다. 여러 인물이 있으면 필요한 기록을 나눠 배분하고, 경계와 지식 제한을 우선합니다. 길이를 넘는 기록은 문장 중간을 자르지 않고 통째로 제외합니다. 갈등·세계관 주입은 이 인물 한도와 별개입니다. 설정을 바꾸면 이전 판독을 버리고 다음 판독부터 새 기준을 씁니다.

페르소나는 **이 채팅에서 유저 사칭 허용**을 켰을 때만 행동·대사 판정 후보에 포함됩니다. 페르소나의 비밀은 다른 인물의 지식으로 자동 전달되지 않습니다.

오류가 나면 팝업의 **오류 로그 복사**를 눌러 문의할 때 보내 주세요. 로그에는 시트 원문·대화·JSON 내용이 포함되지 않습니다.

### 인물의 현재 상태와 장면 흐름

참여 인물의 직전 감정과 충동을 다음 답변의 반응에 참고합니다. **이번 턴 인물 판정**은 인물별로 접혀 있습니다. 이름을 눌러 펼친 뒤 **판정 / 감정값**을 눌러 전환하세요. 감정값은 이름·가로 막대·퍼센트로 표시하며, 모델이 해석한 참고값입니다. 특정 인포 서식을 따로 만들 필요는 없습니다. 수집용 감정값은 채팅 본문에 남기지 않고 이 화면에서만 확인합니다. 읽기에 실패하면 같은 화면에 필수 수치 누락·숫자 표기 오류 등의 이유가 표시됩니다.

**확장 연결모델로 감정 판정 · 현재 채팅**에서 수집 방법을 선택합니다.

- **꺼짐 · 기본값:** 롤플 모델이 답변과 함께 상태를 만듭니다. 스트리밍을 끄고 한 번에 응답 하나를 받는 설정에서 사용합니다.
- **켜짐:** 설정의 **모델·키 설정**에서 선택한 확장 연결모델이 방금 나온 답변, 대상 인물과 앞선 RP 2턴·현재 입력을 읽습니다. 전체 대화나 프리셋을 다시 보내지 않습니다. 추가 호출이 발생하지만 롤플 답변은 먼저 표시됩니다.

체크 항목 옆의 **빠진 감정 수집** 버튼은 항상 표시됩니다. 자동 감정 판정 옵션을 끈 상태에서도, 설정에 저장한 연결 프로필 모델로 현재 선택된 가장 최근 롤플 답변의 **감정값이 저장되지 않은 인물 또는 미반환된 항목만** 읽습니다. 예를 들어 세 명 중 한 명만 빠졌으면 그 사람만 요청하고, 충동·자제만 저장된 인물은 빠진 일반 감정만 보충합니다. 이미 저장된 값은 바꾸지 않습니다. **0%도 저장된 값**이므로 재수집하지 않습니다. 모두 저장돼 있으면 추가 호출 없이 안내만 표시합니다. 같은 답변을 수집 중이면 중복 호출하지 않습니다. 감정만 판독하므로 Jev 전체 판독을 다시 실행하지 않으며 자동 수집 방식도 바꾸지 않습니다. 확장 연결모델의 자동·수동 감정 수집은 시작·완료·실패를 토스트로 알립니다.

연결 프로필 모델은 최신 답변과 함께 **앞선 RP 2턴과 현재 입력**도 참고합니다. 과거 대화는 감정의 계기·대상·변화를 이해하는 용도이며, 최신 답변에 실제로 참여한 인물의 현재 표현만 수집합니다. OOC와 이전 감정 수치 태그는 참고 대화에서 제외합니다. 긴 대화는 최근 내용부터 길이 한도 안에서 읽고, 최신 답변이 수집 한도를 넘으면 일부를 잘라 성공으로 처리하지 않고 안내합니다.

스와이프한 답변은 감정값을 각각 보관하며, 현재 화면에서 선택한 답변의 값만 표시하고 다음 턴에 참고합니다. 선택을 바꾸는 것만으로 모델을 다시 호출하지 않습니다. 답변 내용을 수정하면 해당 값은 비워지므로 필요하면 **빠진 감정 수집**을 누르세요. 보관 범위는 최근 롤플 답변 12개이며, 그 안의 스와이프별 값은 함께 유지합니다.

수집 중 바로 **지금 판독**을 누르거나 다음 답변을 생성하면 수집 완료까지 잠시 기다릴 수 있습니다. 씬판독기가 친밀한 장면에서 진행 개입을 쉬는 동안에는 감정 수집도 쉽니다.

캐릭터는 인물 판정을 켜면 함께 사용하고, 페르소나는 **이 채팅에서 유저 사칭 허용**을 켠 경우에만 포함합니다. 저장한 NPC의 **성적 충동·자제력 추가 판독**은 각 NPC 이름 아래에서 필요한 인물만 체크하세요. 기본값은 꺼짐이며, 켠 NPC만 충동 관련 상태 참고와 육체적 진행 판정에 포함됩니다. 분노·기쁨 같은 감정 수집은 별개입니다. 문자나 통화로 실제 대화에 참여한 NPC도 대상이 될 수 있지만, 다른 인물의 생각에만 등장한 NPC의 감정은 만들어 넣지 않습니다. 수집한 감정이 모두 0이면 0%로 표시해 미수집 상태와 구분합니다.

감정과 스킨십·성적 긴장은 대화·행동·사건과 함께 이어질 수 있습니다. 친밀한 장면에서는 기존 프리셋과 인물 설정의 흐름을 존중하도록 진행 개입을 조절합니다. 구체적인 표현은 롤플레잉 모델과 프리셋을 따릅니다.

## 다음 장면을 위해 기억하는 내용

씬판독기는 채팅별로 진행 상태를 저장하고, 다음 판독에서 최근 대화와 함께 참고합니다. 저장한 내용 중 현재 장면에 필요한 것을 골라 전달해 인물의 반응과 이야기 흐름이 이어지도록 돕습니다.

| 기억하는 내용 | 다음 진행에서 사용하는 방식 |
| --- | --- |
| 관계 변화 | 가까워짐·멀어짐, 신뢰·친밀감·연애 신호와 변화의 근거를 참고해 관계 진행 속도를 조절합니다. |
| 진행 중인 사건 | 사건의 단계·진행 정도·미해결 상태와 최근 사건 기록을 참고해 이어가기·전환·마무리를 판단합니다. |
| 생성한 NPC·빌런 | 현재 인물과 이전에 생성한 인물의 기록을 보관해 이후 장면의 재등장·재사용 후보로 참고합니다. |
| 약속·계획·일정·의무 | 남아 있는 약속이나 책임, 완료·취소 여부, 다른 일로 진행이 어려워진 상태를 연결합니다. **연속성 추론을 켰을 때** 자동으로 추출·검증합니다. |
| 인물별 지식 | 누가 어떤 중요한 정보를 어떤 경로로 알게 됐는지 참고해 다른 인물에게 지식이 섞이는 것을 줄입니다. **연속성 추론을 켰을 때** 자동으로 추출·검증합니다. |
| 직전 감정·충동·자제력 | 현재 선택된 최근 롤플 답변에서 수집한 인물별 상태를 다음 반응에 참고합니다. 최근 답변 12개와 그 스와이프별 값을 보관하며, 수치를 계속 더해 장기 성격으로 만들지는 않습니다. |

약속·계획과 인물별 지식의 자동 누적을 쓰려면 **톱니바퀴 → 모델·키 설정 → 연속성 추론 사용**을 켜고 **SillyTavern 연결 프로필**을 선택하세요. 기본값은 꺼짐입니다. **확장 연결모델로 감정 판정**은 감정 수집 방법을 고르는 별도 설정이므로, 그것만 켜서는 연속성 추론이 켜지지 않습니다. 추출한 후보는 근거와 판정을 거쳐 사용하며, 제안한 전개나 약속을 이미 실행된 사실로 취급하지 않습니다.

### 캐릭터의 기본 설정과 누적 기억의 차이

성격·말투·가치관·관계별 태도·능력과 한계는 사용자가 가져온 **인물 판독 파일**을 기준으로 합니다. 매 턴 필요한 기록을 골라 참고하지만, 대화 중 생긴 변화를 그 파일에 자동으로 덧붙여 성격을 수정하지는 않습니다. 기본 설정을 바꾸려면 원본 시트와 판독 파일을 직접 갱신하세요.

현재 관계 누적은 **채팅 전체 중심**입니다. A와 B, A와 C처럼 모든 인물 쌍의 관계 변화를 각각 세밀하게 쌓는 기능은 아직 없습니다. 다인 캐릭터의 기록과 감정값을 인물별로 나눠 관리하는 기능과도 구분됩니다.

모든 대화를 빠짐없이 장기 기억으로 보관하는 기능은 아닙니다. 항목별 보관 범위 안에서 추출·검증된 상태를 이어 쓰므로 모델이 놓친 내용은 누적되지 않을 수 있습니다. 저장된 기록이 있어도 모델의 오판이나 캐릭터 설정 이탈을 완전히 막아 주지는 않습니다.

## 톱니바퀴 설정

### 전체 사용과 자동 판독

**씬판독기 전체 사용**을 끄면 판독과 주입을 중단합니다. 저장된 시트나 채팅 내용은 삭제하지 않습니다.

**생성 직전에 자동 판독**을 끄면 필요할 때 **지금 판독**을 눌러야 합니다. 입력이나 설정이 바뀌었다면 새 판독이 필요합니다.

### 진행 적극성

기본값은 **1.0**입니다. 모바일에서도 **− / +** 버튼으로 **0.1씩**, **0.5~1.5** 범위에서 바꿉니다. **기본값**을 누르면 1.0으로 돌아갑니다.

- 진행이 너무 답답하면 1.1부터 조금씩 올립니다.
- 너무 많은 진행을 시도하면 0.9부터 조금씩 내립니다.

현재 채팅의 대화·행동·기존 상황 진행을 얼마나 쉽게 채택할지 조절합니다. 가장 신중하게 해도 기본 반응과 작은 시도는 남습니다. 정적·동적 성향, 관계·해결 속도, 등장 확률, 인물의 지식, 실제 실행 여부를 확인하는 기준은 바꾸지 않습니다. 변경 후 새 판독부터 적용됩니다.

### 최근 채팅 범위와 확신도

**최근 채팅 범위**는 1~5턴이며 기본은 3턴입니다. 한 턴은 유저 입력과 그 뒤의 캐릭터 답변입니다. 답변 생성 직전의 현재 입력도 한 턴으로 세므로, 1턴은 직전 캐릭터 답변이 빠질 수 있습니다. 앞뒤 흐름을 보려면 2턴 이상을 사용하세요.

**화면에 확신도 표시**는 결과의 자세한 수치를 보여주는 설정입니다. 끈다고 실제 판정이 달라지지는 않습니다. 확신도는 실제 정답률이나 등장 확률을 뜻하지 않습니다.

### 연속성 추론

앞서 나온 약속·일정·책임·중요한 정보 전달을 이후 장면에 연결하도록 돕습니다. 설정의 확장 연결모델이 찾은 후보를 확인한 뒤 사용합니다. 에코나 반복을 잡는 기능과는 별개입니다.

저장하는 항목과 인물 판독 파일의 차이는 [다음 장면을 위해 기억하는 내용](#다음-장면을-위해-기억하는-내용)을 참고하세요.

**연속성 추론 사용**과 **연결 프로필 선택**은 별개입니다. 인물 JSON 파일을 가져오는 데에는 연결 프로필이 필요하지 않습니다. 연속성 추론을 사용할 때만 해당 설정을 켜세요.

### 주입 위치

주입은 본문 모델이 답변을 만들 때 참고할 지시문을 함께 보내는 것입니다. 별도 채팅 메시지를 추가하는 것은 아닙니다.

선택한 설정과 이번 장면에 필요한 진행·인물 기준을 함께 전달합니다. 여러 기능을 켜도 같은 장면 안에서 어울리도록 조합합니다.

처음에는 **기본 · 깊이 0 · system**을 사용할 수 있습니다. 프리셋의 특정 위치에 넣고 싶다면 항목별로 **프리셋 항목 앞·뒤**를 선택하고, 기준 프롬프트와 삽입 방향을 고르세요. Chat Completion 연결에서 사용하며, 프리셋 원문에 문구를 추가할 필요는 없습니다.

| 넣을 내용 | 설정 항목 |
|---|---|
| 기본 판정·진행·인물 기준 | 기본 판정·전개 주입의 기준 프롬프트와 앞·뒤 |
| 세계관 규칙·시즌 참고 | 세계관 규칙·시즌 참고 주입의 기준 프롬프트와 앞·뒤 |

각각 독립적으로 선택할 수 있으며 같은 위치도 가능합니다. 프리셋 항목 주입을 선택한 내용은 기본 위치에 중복해서 넣지 않습니다. 기준 항목이 삭제·비활성화되었거나 최종 요청에서 내용을 유일하게 찾지 못하면 다른 위치에 임의로 넣지 않고 확인 필요 안내를 표시합니다. 프리셋을 바꿨다면 **프리셋 목록 새로 읽기**로 기준을 확인하세요.

이전 `{{scene-reader}}`, `{{scene-reader-world}}`는 빈 값으로 처리됩니다. 이전 매크로 설정은 프리셋 항목 주입으로 전환되며, 처음에는 활성 프리셋의 `main` 항목 뒤를 기준으로 합니다. 해당 항목이 없거나 꺼져 있다면 직접 다른 기준을 선택하세요. **이전 임시 주입 정리**는 Hub 임시 주입만 비우고 현재 결과를 다시 준비합니다. 저장된 프리셋·채팅·인물 자료·판독 기록을 삭제하지 않습니다.

### 백업과 초기화

**지금 백업**은 현재 설정·세계관·인물 자료·저장 상태를 보관합니다. **다운로드**로 다른 곳에 보관하고, **백업 가져오기**로 복원할 수 있습니다. 다운로드 백업에는 API 키가 포함되지 않습니다.

날짜별 인물 파일과 직접 만든 백업은 사용자가 삭제할 때까지 보관합니다. 자동 백업과 최근 판정 이력은 개수를 제한해 관리하고, 자료를 바꾸거나 삭제하면 불필요한 검색 자료도 정리합니다. 리롤·수정·삭제한 답변의 판정은 현재 선택한 대화에 맞춰 갱신합니다.

초기화 버튼은 이름에 표시된 확장 상태만 지웁니다. 실제 채팅을 지우는 버튼은 아닙니다. 필요하면 먼저 백업하세요.

## 자주 묻는 문제

**버튼이 보이지 않아요.** 확장을 설치한 뒤 새로고침하고, 확장 관리에서 씬판독기가 켜져 있는지 확인하세요.

**플러그인 ZIP이 안 받아져요.** 위의 **서버 플러그인 ZIP 다운로드**는 파일을 바로 받는 링크입니다. 그래도 안 되면 저장소의 **Code → Download ZIP**을 이용하고, 설치 안내에 따라 안의 `server-plugin` 폴더를 옮겨 주세요. 휴대전화에서는 다운로드가 끝났는지 파일 앱에서 확인하세요.

**404가 나와요.** Jev 서버 플러그인의 폴더 위치와 `enableServerPlugins`를 확인한 뒤 SillyTavern을 완전히 재시작하세요.

**임베딩 연결만 실패해요.** **설정 → 모델·키 설정 → 임베딩 모델·키 선택 → 연결 확인**을 눌러 보세요. 로컬은 처음 사용할 때 모델 준비로 시간이 걸릴 수 있습니다. 임베딩 검색이 실패하면 기존 글자 기준 검색으로 판독을 이어갑니다. 복구 후 **임베딩 재시도**으로 다시 준비할 수 있습니다. 문제가 계속되면 설정 버튼 옆 **전체 진단 로그 복사**를 눌러 전달해 주세요. 현재 탭과 관계없이 최근 실행 흐름과 마지막 실패가 포함됩니다. 키 원문·대화 원문·주입문 전문은 포함하지 않습니다. 로그는 현재 실행 중인 화면에 보관되므로 새로고침 전에 복사해 주세요. 서버가 외부 서비스의 세부 오류를 전달하지 않으면 로그에도 그 원인은 미확인으로 표시됩니다.

**401·403이 나와요.** Jev 키를 다시 확인하고 저장하세요. 키 전체를 공개 채팅이나 문의 글에 올리지 마세요.

**시간 초과·502가 나와요.** SillyTavern 서버가 Jev에 연결하지 못했을 수 있습니다. 잠시 뒤 연결 확인을 다시 해보세요.

**인물 기록이 저장되지 않아요.** 팝업의 오류 안내와 **오류 로그 복사**를 확인하세요. JSON 파일이 중간에 잘렸거나 필수 기록 형식이 맞지 않으면 저장하지 않으며, 기존 정상 기록은 유지합니다.

**판정했는데 인물이 안 나와요.** 등장 확률은 추첨 확률입니다. 당첨 뒤에는 구체적으로 가능한 등장 방법을 고르며, 세계관·접근 경로·명시적 제약과 충돌하면 제외될 수 있습니다. 주입문을 받은 본문 모델이 실행을 빠뜨릴 수도 있습니다. 결과의 추첨·제외 이유, 실제 요청 포함 여부와 답변 이행 결과를 확인하세요.

**인물 후보는 있는데 선택이 0개예요.** 인물 탭의 **이번 턴 인물 판정**에서 참여 판정과 0개 이유를 확인하세요. 실제 대화에 참여하지 않았다면 기록을 쓰지 않습니다. 참여 중인데 필요한 기록이 빠졌다면 해당 장면과 판독 결과를 확인하고, 길이 때문에 빠진 경우에만 인물 주입량을 늘려 보세요.

**판독했는데 주입되지 않아요.** 확장 사용과 인물 판정 사용이 켜져 있는지 확인하고, 설정한 주입 방식과 활성 프리셋 기준 항목을 확인하세요. OOC 입력이나 현재 장면에 따라 전달하는 내용이 달라질 수 있습니다. ‘주입 준비됨’은 전달할 내용이 만들어졌다는 뜻이며 실제 요청 포함 여부는 실행 흐름에서 확인합니다. 채팅을 바꾸거나 인물 파일을 수정했다면 현재 상태로 다시 판독해 주세요.

**인물 상태가 수집되지 않아요.** 기본 방식이라면 스트리밍을 끄고 한 번에 응답 하나를 받도록 설정하세요. 연결 프로필 방식을 켰다면 **설정 → 모델·키 설정**에서 프로필을 선택하고 연결을 확인하세요. 해당 인물이 장면에 참여하는지도 확인해 주세요. **감정값**에 수집 중·연결 실패 등의 상태가 표시됩니다. 상태를 받지 못한 턴에도 기존 인물 기록 판독은 계속됩니다.

**진행이 답답해요.** 관계 속도를 빠르게 바꾸기 전에 반복이 실제로 있었는지 결과를 확인하고, 진행 적극성을 조금 올려보세요. 인물의 정보 부족이나 사용자의 결정을 기다려야 하는 상황은 적극성으로 없애지 않습니다.

**OOC에서는 어떻게 되나요?** OOC만 있는 입력은 판독·주입을 건너뜁니다. RP와 OOC가 섞이면 실제 RP와 지시를 구분합니다. 에코·반복 점검은 연속성 추론을 꺼도 작동합니다.

**문의할 때 무엇을 보내나요?** 문제가 생긴 상황과 해당 화면에서 복사한 판정 기록을 알려주세요. 판독 결과가 없을 때에도 복사 버튼으로 최근 진행·실패 기록을 가져올 수 있습니다. 인물 파일을 저장하다 실패했다면 **오류 로그 복사**를 사용하세요. 공유하기 전에 개인정보를 확인하세요.

실제 답변은 본문 모델이 작성합니다. 같은 설정이라도 모델·프리셋·장면에 따라 결과가 달라질 수 있습니다.
